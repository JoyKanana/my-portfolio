# Joy Kanana Portfolio

A beginner portfolio website made with HTML and CSS. It introduces me, what I am learning, and a few interests.

## About the project
This portfolio is a place to practice building a simple website and share my learning journey.

## Included sections
- Home/hero section
- About me
- Skills & technologies
- Education
- Hobbies & interests
- Projects
- Contact

## Technologies used
- HTML5
- CSS3

## Project structure
- index.html — page content and sections
- style.css — layout, colors, cards, and responsive styling
- img.jpeg — profile image used in the hero section

## Features
- Simple layout that adjusts for smaller screens
- Education and hobbies sections
- Project showcase cards
- Contact links for email and LinkedIn

## How to run locally
1. Clone the repository:

```bash
git clone https://github.com/JoyKanana/my-portfolio.git
cd my-portfolio
```

2. Start a local server:

```bash
python3 -m http.server 8000
```

3. Open the project in your browser:

```text
http://localhost:8000
```
