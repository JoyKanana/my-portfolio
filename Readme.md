# Joy Kanana Portfolio

A colorful personal portfolio website built to introduce my work, education, interests, and projects in a modern single-page format.

## About the project
This portfolio was designed to showcase my identity as a web developer and designer. It includes a hero section, about details, skills, education, hobbies, selected projects, and a contact area.

## Included sections
- Home/hero section
- About me
- Skills & technologies
- Education
- Hobbies & interests
- Projects
- Contact

## Technologies used
- HTML5
- CSS3
- JavaScript

## Project structure
- index.html — page content and sections
- style.css — layout, colors, cards, and responsive styling
- script.js — dynamic year and active nav highlighting
- img.jpeg — profile image used in the hero section

## Features
- Modern two-column hero layout
- Responsive design for mobile and desktop
- Colorful, polished styling
- Education and hobbies sections
- Project showcase cards
- Contact links for email and LinkedIn

## How to run locally
1. Clone the repository:

```bash
git clone https://github.com/JoyKanana/my-portfolio.git
cd my-portfolio
```

2. Start a local server:

```bash
python3 -m http.server 8000
```

3. Open the project in your browser:

```text
http://localhost:8000
```
